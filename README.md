# MONOLITH — финансовый контроль

Исходный код интерфейса MONOLITH, экспортированный из AppDeploy.

> **Важно:** текущая версия — демонстрационный прототип. В интерфейсе используются демонстрационные финансовые данные; он не является подтверждённой финансовой отчётностью и не подключён к реальным финансовым источникам.

## Состав проекта

- `src/App.tsx` — основной интерфейс на React.
- `src/index.css` — стили.
- `backend/` — серверные обработчики и realtime-компоненты AppDeploy.
- `tests/tests.json` — сценарии проверок.
- `vite.config.ts`, `tsconfig.json` и конфигурационные файлы — настройки сборки.

## Запуск

Требуется Node.js и npm.

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Зависимость от AppDeploy

Клиентский интерфейс использует обычный `fetch` для вызова `/api/review-change`, поэтому для сборки фронтенда пакет `@appdeploy/client` не требуется. Серверные обработчики в `backend/` используют `@appdeploy/sdk`, который предоставляет среда AppDeploy; для запуска серверной части вне AppDeploy потребуется адаптация этих обработчиков и настройка ИИ/хранилища.

## Безопасность и промышленное использование

Перед промышленным использованием необходимо подключить реальные источники данных, настроить аутентификацию и разграничение доступа, безопасное хранение секретов, аудит, резервное копирование и проверку расчётов. Не храните ключи API и пароли в репозитории.
