# REVIEW.md — MONOLITH

Применять [Adaptive Code Review](.agents/skills/adaptive-code-review/SKILL.md) перед человеческим рассмотрением PR. Режим **DEEP** обязателен для финансовых расчётов, импорта, подтверждения результатов, прав доступа, realtime и CI.

## Что является серьёзным дефектом
- Показатель неправильно рассчитан (или нулём назван отсутствующий факт).
- Итоги не сходятся между дашбордом, сделками, блоками, заказчиками и экспортом.
- Формула смешивает ₽/кг, кг/т, выручку и затраты, НДС с разными базами.
- Подтверждённый результат тихо меняется после нового источника или методики.
- Неверные сопоставления шифра сделки/ОПП или повторные строки удваивают сумму.
- Пользователь видит или изменяет данные без полномочий.
- Проверка считается пройденной без фактического выполнения.

## Изменение формулы — чеклист автора
1. Причина и бухгалтерское определение метрики согласованы.
2. Записаны входные поля, версия источника, единицы, НДС, знак и период.
3. Есть два искусственных примера: обычный и крайний, включая ноль/пропуск.
4. Проверен план/факт и влияние на сумму блоков, общую маржу и экспорт.
5. Добавлены regression/golden-тесты без настоящих финансовых данных.
6. Запущены и процитированы результаты локального test, typecheck и build, при наличии браузерных сценариев — E2E.
7. Критические изменения подтверждены бухгалтером и разработчиком.
8. Откат — отмена отдельного коммита/PR с сохранением прежних версий расчётов.

## Команды после введения тестового контура
- `npm run typecheck` — обязательно после добавления скрипта QA-08.
- `npm test` — обязательно после подключения QA-03.
- `npm run build` — сборка, но **не замена** тестирования.
- Браузерный E2E — при наличии изолированной среды, иначе `NOT RUN`.

В текущем состоянии `package.json` эти команды **не все настроены**. До их фактического появления не писать в отчёте `PASS`.

## Обязательные поля отчёта
`Confirmed: N...`, Verdict, scope (base/head), risk tier, дефекты `файл:строка`, условие воспроизведения, ожидаемое/фактическое, результаты команд `PASS/FAIL/NOT RUN`, потенциальные проблемы отдельно, решение человека, rollback.

**Никакой автопубликации в AppDeploy**. Работа только в отдельных ветках GitHub, пока владелец не разрешил иное.
