# Adaptive Code Review — интеграция в MONOLITH

В репозитории сохранены `SKILL.md` и ключевые справочные файлы из приложенного пользователем пакета версии 1.1.0-chatgpt. Применять совместно с корневым `AGENTS.md` и `REVIEW.md`.

Пакет загруженного ZIP использован при анализе `main` ↔ `feature/cashflow-controls-general-parameters`, а его локальные вспомогательные скрипты проверены (7 успешных тестов). CLI-скрипты и остальные вспомогательные примеры остаются в оригинальном ZIP и **не входят в текущую GitHub-копию**. При необходимости полного автономного пакета копируйте их из исходного архива, сохранив структуру папок.

**Размещение файла в GitHub не означает установки пользовательского скилла в ChatGPT.** Для установки в каталог навыков потребуется действие пользователя через настройки навыков/плагинов, если функция доступна.

Правило: всегда начинать с read-only ревью; менять код и выполнять merge/deploy только после отдельного разрешения. Для финансовых данных выбирать DEEP.
